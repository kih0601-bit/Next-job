Next Job Desktop Helper (선택사항)

- Next Job 사용자용 기능이 아니라 개발 보조도구입니다.
- 약국/공용 PC에는 GitHub CLI 설치 및 개인 GitHub 로그인을 권장하지 않습니다.
- 개인 PC에서만 GitHub CLI(gh) 설치 + gh auth login 후 사용하세요.
- next-job-actions-helper.bat 더블클릭 시 최신 Update job postings Actions를 확인하고,
  실행 중이면 완료를 기다린 뒤 Artifact를 next-job-actions-results 폴더에 다운로드합니다.
- Helper가 없어도 Next Job 엔진/Actions는 정상 작동합니다.
- v89부터 Actions 실행정보(runId/runUrl/주요 시간)는 저장소 data/run-metrics.json에도 자동 기록됩니다.
